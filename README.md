# 🚀 Nombre del Proyecto

Este repositorio contiene el desarrollo de una aplicación backend implementada con **Spring Boot**, desarrollada en el marco de los cursos de la **Universidad UPN**.

---

## 🛠️ Tecnologías y Herramientas

* **Java** (Versión 17 o superior recomendada)
* **Spring Boot** (Framework principal)
* **Spring Web / Spring Data JPA** (Según corresponda)
* **Maven** / **Gradle** (Gestor de dependencias)
* **Base de Datos:** (Ej: MySQL / PostgreSQL / H2)
* **Git & GitHub** (Control de versiones)
